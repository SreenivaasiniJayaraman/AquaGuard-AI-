# AquaGuard AI 💧

AI-powered water waste and leakage risk detection system.

## Problem
Unusual water consumption may indicate water wastage or possible leakage.

## Solution
AquaGuard AI analyzes water usage patterns, identifies risk levels,
provides recommendations, and estimates potential water savings.

## AI Features
- Anomaly detection
- Risk scoring
- Pattern analysis
- Smart recommendations
- Water-saving estimation

## SDG
SDG 6 - Clean Water and Sanitation

## Technologies
Python, Pandas, NumPy, Streamlit
